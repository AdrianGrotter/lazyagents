# Daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the lazyagents daemon and a headless CLI on top of it. The daemon owns agent processes and their terminals, keeps going when clients quit, persists agents, and tracks Claude status through hooks. The CLI covers `daemon`, `hook`, `ls`, `project add/rm`, `new`, `kill`, `restart`, `rm`, `rename` and `shutdown`.

**Architecture:** Milestones 2, 3 and 5 of the spec, plus a minimal lifecycle surface. `crates/protocol` defines messages, framing, the screen model and state paths. `crates/daemon` runs one tokio loop that owns the agents: alacritty terminals ported from the spike, a persisted store, status logic and frame diffing. It serves clients over a Unix socket. `crates/client` connects to the daemon, or spawns it if needed. `crates/lazyagents` is the CLI. The TUI (plan 3) will be another client of the same protocol.

**Tech Stack:** Rust 2024; tokio 1.53.3; postcard 1.1.3 (`use-std`); serde 1.0.229; uuid 1.28.0 (`v4`, `serde`); toml 1.1.8; tracing 0.1.44 and tracing-subscriber 0.3.23; alacritty_terminal 0.26.0; serde_json 1; clap 4.6.7; anyhow; tempfile 3.27.0 (dev only).

**Spec:** `docs/superpowers/specs/2026-10-15-lazyagents-design.md` (sections 2, 2.1–2.4, 2.6, 4, 7). Decisions: `docs/decisions/0001`, `0003` and `0005`.

**Scope:** Plan 2 of 3. Not included: the TUI, worktrees, diff view, config/keybindings and selection (all plan 3). The `spike/` crate stays until plan 3's TUI replaces it.

## Global Constraints

- All tooling comes from the nix dev shell; run every cargo, just or git-commit command as `nix develop -c <cmd>`. Install nothing globally.
- Rust edition 2024. Workspace lints: `unsafe_code = "forbid"`, which rules out `std::env::set_var`/`remove_var`; pass environment to child `Command`s instead. Clippy runs with `-D warnings`.
- Pin crate versions in `[workspace.dependencies]` exactly as Task 2 lists them. `Cargo.lock` is committed and `just` recipes use `--locked`.
- Commits follow Conventional Commits:
  - types: `feat fix docs refactor test chore build ci perf`
  - scopes: `protocol daemon tui cli docs nix repo spike`, plus `client`, which Task 8 adds to the commit-msg hook
  - the first line is at most 72 characters
- Comments: none by default. Write one only for a non-obvious invariant or constraint, and never narrate changes.
- Tests and dev runs always use a temp `LAZYAGENTS_STATE_DIR`. `~/.local/state/lazyagents` belongs to the user's real agents.
- No test may leave a daemon, agent, or spike process running, even when it fails. Every test that starts one shuts it down through a guard's `Drop`. The user has already hit leaked processes, so the checkpoints treat any leftover as a failure.
- The tmux harness uses only its private server (`scripts/tmux-harness.sh`).
- `lazyagents hook` never blocks or fails Claude. It finishes within about 200 ms, always exits 0, and prints nothing.
- If plan code fails to compile against a real crate API (tokio, postcard, toml, uuid, clap, alacritty), make the minimal correction and record it in the task report. Test expectations do not change; a test you believe is wrong is reported, not edited.

At each checkpoint the executor runs the listed commands and pastes their tails into the task report. It continues only when every expectation holds.

## Review Focus

1. **Leaked processes.** After `shutdown`, a failing test, or a client that quits, no daemon or agent may survive. Tests: Task 7 `shutdown_stops_agents_and_removes_socket`, Task 9 `shutdown_leaves_no_agent_processes` and the `TestEnv` guard.
2. **Stale socket after a crash.** If a dead daemon left `daemon.sock` behind, the next start removes it and serves. Tests: Task 7 `stale_socket_file_is_replaced`, Task 9 `cli_recovers_from_a_stale_socket`.
3. **Two daemons on one state dir.** The second refuses with a clear error and leaves the first serving. Test: Task 7 `second_daemon_refuses_to_start`.
4. **Hooks for unknown agents, or with no daemon.** The daemon answers with an error and keeps running; `lazyagents hook` exits 0 silently within the budget. Tests: Task 7 `hook_for_unknown_agent_is_an_error`, Task 9 `hook_is_silent_and_fast_without_daemon`.
5. **Corrupt `state.toml`.** The daemon refuses to start and names the file, rather than overwriting the user's data with an empty state. Tests: Task 4 `corrupt_file_is_an_error_naming_the_path`, Task 7 `corrupt_state_prevents_start`.

```rust
mod tests {
    use super::*;

    fn screen_with(text_rows: &[&str], cols: u16) -> Screen {
        let mut screen = Screen::blank(cols, text_rows.len() as u16);
        for (row, text) in text_rows.iter().enumerate() {
            for (col, ch) in text.chars().enumerate() {
                screen.lines[row][col].text = ch.to_string();
            }
        }
        screen
    }

    #[test]
    fn blank_screen_is_spaces_and_empty_text() {
        let screen = Screen::blank(3, 2);
        assert_eq!(screen.lines.len(), 2);
        assert_eq!(screen.lines[1].len(), 3);
        assert_eq!(screen.text(), "");
    }

    #[test]
    fn first_diff_is_full() {
        let agent = AgentId::random();
        let screen = screen_with(&["ab", "cd"], 4);
        let frame = screen.diff(None, agent).expect("frame");
        assert!(frame.full);
        assert_eq!(frame.lines.len(), 2);
        assert_eq!(frame.agent, agent);
    }

    #[test]
    fn identical_screens_produce_no_frame() {
        let screen = screen_with(&["ab", "cd"], 4);
        assert_eq!(screen.diff(Some(&screen.clone()), AgentId::random()), None);
    }

    #[test]
    fn only_changed_rows_are_sent() {
        let before = screen_with(&["ab", "cd", "ef"], 4);
        let after = screen_with(&["ab", "cX", "ef"], 4);
        let frame = after.diff(Some(&before), AgentId::random()).expect("frame");
        assert!(!frame.full);
        assert_eq!(frame.lines.len(), 1);
        assert_eq!(frame.lines[0].index, 1);
    }

    #[test]
    fn cursor_move_alone_produces_a_frame_without_rows() {
        let before = screen_with(&["ab"], 4);
        let mut after = before.clone();
        after.cursor = Some((2, 0));
        let frame = after.diff(Some(&before), AgentId::random()).expect("frame");
        assert!(frame.lines.is_empty());
        assert_eq!(frame.cursor, Some((2, 0)));
    }

    #[test]
    fn resize_forces_a_full_frame() {
        let before = screen_with(&["ab"], 4);
        let after = screen_with(&["ab"], 5);
        assert!(after.diff(Some(&before), AgentId::random()).expect("frame").full);
    }

    #[test]
    fn applying_diffs_reproduces_the_screen() {
        let agent = AgentId::random();
        let first = screen_with(&["hello", "world"], 6);
        let mut second = screen_with(&["hello", "there"], 6);
        second.cursor = Some((5, 1));

        let mut mirror = Screen::blank(0, 0);
        mirror.apply(&first.diff(None, agent).expect("frame"));

        mirror.apply(&second.diff(Some(&first), agent).expect("frame"));
```

```rust
pub async fn write_message<W, T>(writer: &mut W, message: &T) -> io::Result<()>
where
    W: AsyncWrite + Unpin,
    T: Serialize,
{
    let bytes = postcard::to_stdvec(message)
        .map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e))?;
    let len = u32::try_from(bytes.len())
        .ok()
        .filter(|&len| len as usize <= MAX_MESSAGE_LEN)
        .ok_or_else(|| io::Error::new(io::ErrorKind::InvalidData, "message too large"))?;
    writer.write_all(&len.to_be_bytes()).await?;
    writer.write_all(&bytes).await?;
    writer.flush().await
}

pub async fn read_message<R, T>(reader: &mut R) -> io::Result<Option<T>>
where
    R: AsyncRead + Unpin,
    T: DeserializeOwned,
{
    let mut len = [0u8; 4];
    match reader.read_exact(&mut len).await {
        Ok(_) => {}
        Err(e) if e.kind() == io::ErrorKind::UnexpectedEof => return Ok(None),
        Err(e) => return Err(e),
    }
    let len = u32::from_be_bytes(len) as usize;
    if len > MAX_MESSAGE_LEN {
        return Err(io::Error::new(io::ErrorKind::InvalidData, "message too large"));
    }
    let mut buf = vec![0; len];
    reader.read_exact(&mut buf).await?;
    postcard::from_bytes(&buf)
        .map(Some)
        .map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e))
}
```

```rust
pub fn spawn_spec(record: &AgentRecord, launch: Launch, ctx: &SpawnContext<'_>) -> SpawnSpec {
    let mut argv = record.command.clone();
    if argv.is_empty() {
        argv.push("claude".to_string());
    }
    if record.kind == AgentKind::Claude {
        if let Some(session) = record.session_id {
            let flag = if launch == Launch::Resume && record.resumable {
                "--resume"
            } else {
                "--session-id"
            };
            argv.push(flag.to_string());
            argv.push(session.to_string());
        }
        argv.push("--settings".to_string());
        argv.push(ctx.paths.hook_settings(record.id).display().to_string());
    }

    let (program, args) = match ctx.direnv.zip(find_envrc(&record.cwd, ctx.project_root)) {
        Some((direnv, dir)) => {
            let mut args = vec!["exec".to_string(), dir.display().to_string()];
            args.extend(argv);
            (direnv.display().to_string(), args)
        }
        None => {
            let program = argv.remove(0);
            (program, argv)
        }
    };

    let env = HashMap::from([
        ("LAZYAGENTS_AGENT_ID".to_string(), record.id.to_string()),
        ("LAZYAGENTS_SOCKET".to_string(), ctx.paths.socket().display().to_string()),
    ]);
    SpawnSpec {
        program,
        args,
        cwd: record.cwd.clone(),
        env,
    }
}

pub fn find_envrc(cwd: &Path, root: &Path) -> Option<PathBuf> {
    for dir in cwd.ancestors() {
        if dir.join(".envrc").is_file() {
            return Some(dir.to_path_buf());
        }
        if dir == root || !dir.starts_with(root) {
            break;
        }
    }
    None
}

pub fn hook_settings(exe: &Path) -> Value {
    let exe = shell_quote(&exe.display().to_string());
    let hooks: serde_json::Map<String, Value> = HookKind::ALL
        .into_iter()
        .map(|kind| {
            let command = format!("{exe} hook {}", kind.name());
            let entry = json!([{ "hooks": [{ "type": "command", "command": command, "timeout": 5 }] }]);
            (kind.name().to_string(), entry)
        })
        .collect();
    json!({ "hooks": hooks })
}

pub fn shell_quote(value: &str) -> String {
    format!("'{}'", value.replace('\'', r"'\''"))
}
```

```rust
pub fn screen_of<T: EventListener>(term: &Term<T>) -> Screen {
    let mut screen = Screen::blank(term.columns() as u16, term.screen_lines() as u16);
    let content = term.renderable_content();
    let offset = content.display_offset as i32;
    for indexed in content.display_iter {
        let Ok(row) = usize::try_from(indexed.point.line.0 + offset) else {
            continue;
        };
        if let Some(target) = screen
            .lines
            .get_mut(row)
            .and_then(|line| line.get_mut(indexed.point.column.0))
        {
            *target = convert(indexed.cell);
        }
    }
    let cursor = content.cursor;
    let visible = content.mode.contains(TermMode::SHOW_CURSOR) && cursor.shape != CursorShape::Hidden;
    screen.cursor = visible
        .then(|| {
            let row = u16::try_from(cursor.point.line.0 + offset).ok()?;
            let col = u16::try_from(cursor.point.column.0).ok()?;
            (row < screen.rows && col < screen.cols).then_some((col, row))
        })
        .flatten();
    screen
}
```

**Interfaces:**
- Consumes: everything from Tasks 2–6.
- Produces:
  - `daemon::Config { paths: StatePaths, exe: PathBuf }`. `exe` is the program the generated Claude hook settings invoke as `'<exe>' hook <Event>`.
  - `pub async fn daemon::run(Config) -> anyhow::Result<()>`:
    - It refuses to start if another daemon answers on the socket, removes a stale socket file, and refuses to start on a corrupt `state.toml`.
    - It serves until it receives `Request::Shutdown`. It then answers the request, stops every agent, waits up to 1 s for client writers to flush, and removes the socket.
- Behaviour contract (these tests pin it):
  - Loaded agents start as `Stopped`.
  - `CreateAgent`:
    - Validates the name: 1–64 characters from `[A-Za-z0-9._-]`, not starting with `-` or `.`, and unique within the project.
    - Requires a command for `Generic`. Sets `cwd` to the project path.
    - Starts the agent. Claude agents get a fresh session id and a written hook settings file; status is `Starting`.
    - Persists the agent and broadcasts `AgentUpdated`.
    - If the spawn fails, the record is kept with status `Exited(127)` and the request returns `Err("failed to start ...")`.
  - `KillAgent` drops the terminal and sets the status to `Stopped`.
  - `RestartAgent` starts the agent again. A Claude agent resumes its session when `resumable`; otherwise it gets a new session id.
  - `RemoveAgent` drops the terminal, deletes the hook settings file, persists, broadcasts `AgentRemoved` and clears subscriptions to that agent.
  - `RenameAgent` validates the new name the same way `CreateAgent` does.
  - `AddProject` canonicalizes the path and requires a directory. An already-known path returns the existing project. The name defaults to the directory name. It persists and broadcasts `ProjectsChanged`.
  - `RemoveProject` fails while agents reference the project.
  - `Subscribe` makes the next tick send that client a full `Frame`, then diffs.
  - `Input` fails if the agent is not running. A key or paste scrolls to the bottom and writes the encoded bytes; a wheel event that encodes to `None` scrolls the scrollback by ±3.
  - `Hook`:
    - Fails for an unknown agent.
    - For a running Claude agent, it sets the status from `on_hook`.
    - `UserPromptSubmit` sets `resumable` and persists.
    - `SessionStart` with a different, parseable session id adopts it, clears `resumable` and persists.
  - The tick runs every 33 ms. It recomputes generic agents' status from output activity, broadcasting changes, and sends frame diffs to subscribed clients.
  - Terminal events from an older generation of an agent are ignored.

```rust
struct Conn {
    read: OwnedReadHalf,
    write: OwnedWriteHalf,
    next_id: u64,
    pending: Vec<ServerMessage>,
    screen: Screen,
}

impl Conn {
    async fn open(dir: &Path) -> Self {
        let stream = UnixStream::connect(StatePaths::new(dir).socket()).await.expect("connect");
        let (mut read, mut write) = stream.into_split();
        let welcome: ServerMessage = read_message(&mut read).await.expect("read").expect("welcome");
        assert!(matches!(welcome, ServerMessage::Welcome { protocol_version, .. } if protocol_version == PROTOCOL_VERSION));
        write_message(&mut write, &ClientMessage::Hello { protocol_version: PROTOCOL_VERSION })
            .await
            .expect("hello");
        Self { read, write, next_id: 1, pending: Vec::new(), screen: Screen::blank(0, 0) }
    }

    async fn request(&mut self, request: Request) -> Result<Response, String> {
        let id = self.next_id;
        self.next_id += 1;
        write_message(&mut self.write, &ClientMessage::Request { id, request }).await.expect("send");
        loop {
            let message = self.next().await;
            match message {
                ServerMessage::Response { id: got, result } if got == id => return result,
                other => self.pending.push(other),
            }
        }
    }

    async fn next(&mut self) -> ServerMessage {
        tokio::time::timeout(WAIT, read_message::<_, ServerMessage>(&mut self.read))
            .await
            .expect("timed out waiting for a message")
            .expect("read")
            .expect("daemon closed the connection")
    }

    async fn wait_for(&mut self, mut predicate: impl FnMut(&ServerMessage) -> bool) -> ServerMessage {
        if let Some(index) = self.pending.iter().position(&mut predicate) {
            return self.pending.remove(index);
        }
        loop {
            let message = self.next().await;
            if predicate(&message) {
                return message;
            }
            self.pending.push(message);
        }
    }

    async fn wait_status(&mut self, id: AgentId, status: Status) {
        self.wait_for(|m| matches!(m, ServerMessage::AgentUpdated(info) if info.id == id && info.status == status))
            .await;
    }

    async fn wait_text(&mut self, id: AgentId, needle: &str) -> String {
        let deadline = tokio::time::Instant::now() + WAIT;
        loop {
            let pending = std::mem::take(&mut self.pending);
            for message in pending {
                match message {
                    ServerMessage::Frame(frame) if frame.agent == id => self.screen.apply(&frame),
                    other => self.pending.push(other),
                }
            }
            if self.screen.text().contains(needle) {
                return self.screen.text();
            }
            assert!(tokio::time::Instant::now() < deadline, "never saw {needle:?}; screen:\n{}", self.screen.text());
            let message = self.next().await;
            self.pending.push(message);
        }
    }
}
```

```rust
pub async fn run(config: Config) -> anyhow::Result<()> {
    let paths = config.paths;
    std::fs::create_dir_all(paths.dir()).with_context(|| format!("creating {}", paths.dir().display()))?;
    let socket = paths.socket();
    if socket.exists() {
        if UnixStream::connect(&socket).await.is_ok() {
            anyhow::bail!("a daemon is already listening on {}", socket.display());
        }
        std::fs::remove_file(&socket).with_context(|| format!("removing stale {}", socket.display()))?;
    }
    let state = store::load(&paths.state_file())?;
    let listener = UnixListener::bind(&socket).with_context(|| format!("binding {}", socket.display()))?;
    tracing::info!(socket = %socket.display(), "daemon listening");

    let (incoming_tx, mut incoming) = mpsc::unbounded_channel::<UnixStream>();
    let (commands_tx, mut commands) = mpsc::unbounded_channel::<Command>();
    let (events_tx, mut events) = mpsc::unbounded_channel::<TerminalEvent>();
    let accept = tokio::spawn(accept_loop(listener, incoming_tx));
    let mut readers = JoinSet::new();
    let mut writers = JoinSet::new();
    let mut daemon = Daemon::new(paths.clone(), config.exe, state, events_tx);
    let mut next_client: ClientId = 1;
    let mut tick = tokio::time::interval(TICK);
    tick.set_missed_tick_behavior(MissedTickBehavior::Skip);

    loop {
        tokio::select! {
            Some(stream) = incoming.recv() => {
                let client = next_client;
                next_client += 1;
                let (tx, rx) = mpsc::unbounded_channel();
                daemon.add_client(client, tx);
                let (read, write) = stream.into_split();
                readers.spawn(read_loop(client, read, commands_tx.clone()));
                writers.spawn(write_loop(write, rx));
            }
            Some(command) = commands.recv() => {
                if daemon.handle_command(command) == Flow::Stop {
                    break;
                }
            }
            Some(event) = events.recv() => daemon.handle_terminal_event(event),
            _ = tick.tick() => daemon.tick(),
        }
    }

    accept.abort();
    drop(daemon);
    let _ = tokio::time::timeout(Duration::from_secs(1), async {
        while writers.join_next().await.is_some() {}
    })
    .await;
    readers.abort_all();
    let _ = std::fs::remove_file(&socket);
    tracing::info!("daemon stopped");
    Ok(())
}

async fn accept_loop(listener: UnixListener, incoming: UnboundedSender<UnixStream>) {
    loop {
        match listener.accept().await {
            Ok((stream, _)) => {
                if incoming.send(stream).is_err() {
                    break;
                }
            }
            Err(e) => tracing::warn!(error = %e, "accept failed"),
        }
    }
}

async fn read_loop(client: ClientId, mut read: OwnedReadHalf, commands: UnboundedSender<Command>) {
    loop {
        match read_message::<_, ClientMessage>(&mut read).await {
            Ok(Some(ClientMessage::Request { id, request })) => {
                if commands.send(Command::Request { client, id, request }).is_err() {
                    break;
                }
            }
            Ok(Some(ClientMessage::Hello { .. })) => {}
            Ok(None) | Err(_) => break,
        }
    }
    let _ = commands.send(Command::Disconnected { client });
}

async fn write_loop(mut write: OwnedWriteHalf, mut outgoing: UnboundedReceiver<ServerMessage>) {
    while let Some(message) = outgoing.recv().await {
        if write_message(&mut write, &message).await.is_err() {
            break;
        }
    }
}

struct Agent {
    record: AgentRecord,
    status: Status,
    terminal: Option<Terminal>,
    generation: u64,
    last_output: Option<Instant>,
    dirty: bool,
}

struct Subscription {
    agent: AgentId,
    last: Option<Screen>,
}

struct Client {
    tx: UnboundedSender<ServerMessage>,
    subscription: Option<Subscription>,
}

struct Daemon {
    paths: StatePaths,
    exe: PathBuf,
    direnv: Option<PathBuf>,
    projects: Vec<Project>,
    agents: HashMap<AgentId, Agent>,
    clients: HashMap<ClientId, Client>,
    events: UnboundedSender<TerminalEvent>,
}

impl Daemon {
    fn new(paths: StatePaths, exe: PathBuf, state: StoredState, events: UnboundedSender<TerminalEvent>) -> Self {
        let agents = state
            .agents
            .into_iter()
            .map(|record| {
                let agent = Agent {
                    record,
                    status: Status::Stopped,
                    terminal: None,
                    generation: 0,
                    last_output: None,
                    dirty: false,
                };
                (agent.record.id, agent)
            })
            .collect();
        Self {
            paths,
            exe,
            direnv: find_in_path("direnv"),
            projects: state.projects,
            agents,
            clients: HashMap::new(),
            events,
        }
    }

    fn add_client(&mut self, client: ClientId, tx: UnboundedSender<ServerMessage>) {
        let _ = tx.send(ServerMessage::Welcome {
            protocol_version: PROTOCOL_VERSION,
            daemon_version: env!("CARGO_PKG_VERSION").to_string(),
        });
        self.clients.insert(client, Client { tx, subscription: None });
    }

    fn handle_command(&mut self, command: Command) -> Flow {
        match command {
            Command::Request { client, id, request } => {
                let stop = matches!(request, Request::Shutdown);
                let result = self.handle_request(client, request);
                if let Some(c) = self.clients.get(&client) {
                    let _ = c.tx.send(ServerMessage::Response { id, result });
                }
                if stop { Flow::Stop } else { Flow::Continue }
            }
            Command::Disconnected { client } => {
                self.clients.remove(&client);
                Flow::Continue
            }
        }
    }

    fn handle_request(&mut self, client: ClientId, request: Request) -> Result<Response, String> {
        match request {
            Request::ListProjects => Ok(Response::Projects(self.projects.clone())),
            Request::AddProject { path, name } => self.add_project(&path, name).map(Response::Project),
            Request::RemoveProject { id } => self.remove_project(id).map(|()| Response::Ok),
            Request::ListAgents => Ok(Response::Agents(self.list_agents())),
            Request::CreateAgent(create) => self.create_agent(create).map(Response::Agent),
            Request::KillAgent { id } => self.kill_agent(id).map(Response::Agent),
            Request::RestartAgent { id, cols, rows } => self
                .restart_agent(id, PaneSize::new(cols, rows))
                .map(Response::Agent),
            Request::RemoveAgent { id } => self.remove_agent(id).map(|()| Response::Ok),
            Request::RenameAgent { id, name } => self.rename_agent(id, name).map(Response::Agent),
            Request::Subscribe { id } => {
                self.agent(id)?;
                if let Some(c) = self.clients.get_mut(&client) {
                    c.subscription = Some(Subscription { agent: id, last: None });
                }
                Ok(Response::Ok)
            }
            Request::Unsubscribe => {
                if let Some(c) = self.clients.get_mut(&client) {
                    c.subscription = None;
                }
                Ok(Response::Ok)
            }
            Request::Input { id, event } => self.input(id, &event).map(|()| Response::Ok),
            Request::Resize { id, cols, rows } => {
                let agent = self.running_mut(id)?;
                if let Some(t) = agent.terminal.as_mut() {
                    t.resize(PaneSize::new(cols, rows));
                }
                agent.dirty = true;
                Ok(Response::Ok)
            }
            Request::Scroll { id, lines } => {
                let agent = self.running_mut(id)?;
                if let Some(t) = agent.terminal.as_ref() {
                    t.scroll(lines);
                }
                agent.dirty = true;
                Ok(Response::Ok)
            }
            Request::Hook { id, kind, session_id } => self.hook(id, kind, session_id).map(|()| Response::Ok),
            Request::Shutdown => Ok(Response::Ok),
        }
    }

    fn agent(&self, id: AgentId) -> Result<&Agent, String> {
        self.agents.get(&id).ok_or_else(|| format!("unknown agent {id}"))
    }

    fn running_mut(&mut self, id: AgentId) -> Result<&mut Agent, String> {
        let agent = self.agents.get_mut(&id).ok_or_else(|| format!("unknown agent {id}"))?;
        if agent.terminal.is_none() {
            return Err(format!("{} is not running", agent.record.name));
        }
        Ok(agent)
    }

    fn info(agent: &Agent) -> AgentInfo {
        AgentInfo {
            id: agent.record.id,
            project: agent.record.project,
            name: agent.record.name.clone(),
            kind: agent.record.kind,
            command: agent.record.command.clone(),
            cwd: agent.record.cwd.clone(),
            status: agent.status,
        }
    }

    fn info_of(&self, id: AgentId) -> Result<AgentInfo, String> {
        self.agent(id).map(Self::info)
    }

    fn list_agents(&self) -> Vec<AgentInfo> {
        let position = |project: ProjectId| self.projects.iter().position(|p| p.id == project);
        let mut infos: Vec<AgentInfo> = self.agents.values().map(Self::info).collect();
        infos.sort_by(|a, b| (position(a.project), &a.name).cmp(&(position(b.project), &b.name)));
        infos
    }

    fn broadcast(&self, message: &ServerMessage) {
        for client in self.clients.values() {
            let _ = client.tx.send(message.clone());
        }
    }

    fn announce(&self, id: AgentId) {
        if let Ok(info) = self.info_of(id) {
            self.broadcast(&ServerMessage::AgentUpdated(info));
        }
    }

    fn persist(&self) {
        let mut agents: Vec<AgentRecord> = self.agents.values().map(|a| a.record.clone()).collect();
        agents.sort_by(|a, b| (a.project, &a.name).cmp(&(b.project, &b.name)));
        let state = StoredState { projects: self.projects.clone(), agents };
        if let Err(e) = store::save(&self.paths.state_file(), &state) {
            tracing::error!(error = %format!("{e:#}"), "persisting state failed");
        }
    }

    fn add_project(&mut self, path: &Path, name: Option<String>) -> Result<Project, String> {
        let path = path.canonicalize().map_err(|e| format!("{}: {e}", path.display()))?;
        if !path.is_dir() {
            return Err(format!("{} is not a directory", path.display()));
        }
        if let Some(existing) = self.projects.iter().find(|p| p.path == path) {
            return Ok(existing.clone());
        }
        let name = name
            .filter(|n| !n.trim().is_empty())
            .or_else(|| path.file_name().map(|n| n.to_string_lossy().into_owned()))
            .unwrap_or_else(|| path.display().to_string());
        let project = Project { id: ProjectId::random(), name, path };
        self.projects.push(project.clone());
        self.persist();
        self.broadcast(&ServerMessage::ProjectsChanged(self.projects.clone()));
        Ok(project)
    }

    fn remove_project(&mut self, id: ProjectId) -> Result<(), String> {
        if self.agents.values().any(|a| a.record.project == id) {
            return Err("remove the project's agents first".into());
        }
        let before = self.projects.len();
        self.projects.retain(|p| p.id != id);
        if self.projects.len() == before {
            return Err(format!("unknown project {id}"));
        }
        self.persist();
        self.broadcast(&ServerMessage::ProjectsChanged(self.projects.clone()));
        Ok(())
    }

    fn validate_name(&self, project: ProjectId, name: &str, except: Option<AgentId>) -> Result<(), String> {
        let valid = !name.is_empty()
            && name.len() <= 64
            && !name.starts_with(['-', '.'])
            && name.chars().all(|c| c.is_ascii_alphanumeric() || matches!(c, '.' | '_' | '-'));
        if !valid {
            return Err(format!(
                "invalid agent name {name:?}: use 1-64 of A-Z a-z 0-9 . _ -, not starting with - or ."
            ));
        }
        let taken = self
            .agents
            .values()
            .any(|a| a.record.project == project && a.record.name == name && Some(a.record.id) != except);
        if taken {
            return Err(format!("an agent named {name} already exists in this project"));
        }
        Ok(())
    }

    fn create_agent(&mut self, create: CreateAgent) -> Result<AgentInfo, String> {
        let project = self
            .projects
            .iter()
            .find(|p| p.id == create.project)
            .cloned()
            .ok_or_else(|| format!("unknown project {}", create.project))?;
        self.validate_name(project.id, &create.name, None)?;
        if create.kind == AgentKind::Generic && create.command.is_empty() {
            return Err("a generic agent needs a command".into());
        }
        let record = AgentRecord {
            id: AgentId::random(),
            project: project.id,
            name: create.name,
            kind: create.kind,
            command: create.command,
            cwd: project.path.clone(),
            session_id: None,
            resumable: false,
        };
        let id = record.id;
        self.agents.insert(
            id,
            Agent { record, status: Status::Stopped, terminal: None, generation: 0, last_output: None, dirty: false },
        );
        let started = self.start(id, Launch::Fresh, PaneSize::new(create.cols, create.rows));
        self.persist();
        self.announce(id);
        started?;
        self.info_of(id)
    }

    fn start(&mut self, id: AgentId, launch: Launch, size: PaneSize) -> Result<(), String> {
        let project_root = {
            let agent = self.agent(id)?;
            self.projects
                .iter()
                .find(|p| p.id == agent.record.project)
                .map(|p| p.path.clone())
                .unwrap_or_else(|| agent.record.cwd.clone())
        };
        let agent = self.agents.get_mut(&id).ok_or_else(|| format!("unknown agent {id}"))?;
        agent.terminal = None;
        agent.generation += 1;
        let resume = launch == Launch::Resume && agent.record.resumable;
        if agent.record.kind == AgentKind::Claude {
            if !resume {
                agent.record.session_id = Some(Uuid::new_v4());
                agent.record.resumable = false;
            }
            let settings = self.paths.hook_settings(id);
            let written = std::fs::create_dir_all(self.paths.hooks_dir())
                .and_then(|()| std::fs::write(&settings, hook_settings(&self.exe).to_string()));
            if let Err(e) = written {
                agent.status = Status::Exited(127);
                return Err(format!("writing {}: {e}", settings.display()));
            }
        }
        let ctx = SpawnContext {
            paths: &self.paths,
            project_root: &project_root,
            direnv: self.direnv.as_deref(),
        };
        let spec = spawn_spec(&agent.record, if resume { Launch::Resume } else { Launch::Fresh }, &ctx);
        match Terminal::spawn(&spec, size, Proxy::new(id, agent.generation, self.events.clone())) {
            Ok(terminal) => {
                agent.terminal = Some(terminal);
                agent.status = Status::Starting;
                agent.last_output = None;
                agent.dirty = true;
                Ok(())
            }
            Err(e) => {
                agent.status = Status::Exited(127);
                Err(format!("{e:#}"))
            }
        }
    }

    fn kill_agent(&mut self, id: AgentId) -> Result<AgentInfo, String> {
        let agent = self.agents.get_mut(&id).ok_or_else(|| format!("unknown agent {id}"))?;
        agent.terminal = None;
        agent.generation += 1;
        agent.status = Status::Stopped;
        agent.dirty = true;
        self.announce(id);
        self.info_of(id)
    }

    fn restart_agent(&mut self, id: AgentId, size: PaneSize) -> Result<AgentInfo, String> {
        let started = self.start(id, Launch::Resume, size);
        self.persist();
        self.announce(id);
        started?;
        self.info_of(id)
    }

    fn remove_agent(&mut self, id: AgentId) -> Result<(), String> {
        self.agents.remove(&id).ok_or_else(|| format!("unknown agent {id}"))?;
        let _ = std::fs::remove_file(self.paths.hook_settings(id));
        for client in self.clients.values_mut() {
            if client.subscription.as_ref().is_some_and(|s| s.agent == id) {
                client.subscription = None;
            }
        }
        self.persist();
        self.broadcast(&ServerMessage::AgentRemoved(id));
        Ok(())
    }

    fn rename_agent(&mut self, id: AgentId, name: String) -> Result<AgentInfo, String> {
        let project = self.agent(id)?.record.project;
        self.validate_name(project, &name, Some(id))?;
        if let Some(agent) = self.agents.get_mut(&id) {
            agent.record.name = name;
        }
        self.persist();
        self.announce(id);
        self.info_of(id)
    }

    fn input(&mut self, id: AgentId, event: &InputEvent) -> Result<(), String> {
        let agent = self.running_mut(id)?;
        let Some(terminal) = agent.terminal.as_ref() else {
            return Ok(());
        };
        match (encode(event, terminal.mode()), event) {
            (Some(bytes), InputEvent::Wheel { .. }) => terminal.write(bytes),
            (Some(bytes), _) => {
                terminal.scroll_to_bottom();
                terminal.write(bytes);
            }
            (None, InputEvent::Wheel { up, .. }) => {
                terminal.scroll(if *up { WHEEL_LINES } else { -WHEEL_LINES });
            }
            (None, _) => {}
        }
        agent.dirty = true;
        Ok(())
    }

    fn hook(&mut self, id: AgentId, kind: HookKind, session_id: Option<String>) -> Result<(), String> {
        let agent = self.agents.get_mut(&id).ok_or_else(|| format!("unknown agent {id}"))?;
        if agent.record.kind != AgentKind::Claude || agent.terminal.is_none() {
            return Ok(());
        }
        let mut changed_record = false;
        if kind == HookKind::UserPromptSubmit && !agent.record.resumable {
            agent.record.resumable = true;
            changed_record = true;
        }
        if kind == HookKind::SessionStart
            && let Some(session) = session_id.and_then(|s| s.parse::<Uuid>().ok())
            && agent.record.session_id != Some(session)
        {
            agent.record.session_id = Some(session);
            agent.record.resumable = false;
            changed_record = true;
        }
        agent.status = on_hook(kind);
        if changed_record {
            self.persist();
        }
        self.announce(id);
        Ok(())
    }

    fn handle_terminal_event(&mut self, event: TerminalEvent) {
        let Some(agent) = self.agents.get_mut(&event.agent) else {
            return;
        };
        if agent.generation != event.generation {
            return;
        }
        let Some(terminal) = agent.terminal.as_mut() else {
            return;
        };
        match terminal.handle(event.event) {
            Outcome::Output => {
                agent.dirty = true;
                agent.last_output = Some(Instant::now());
            }
            Outcome::Exited(code) => {
                agent.status = Status::Exited(code);
                agent.dirty = true;
                self.announce(event.agent);
            }
            Outcome::Nothing => {}
        }
    }

    fn tick(&mut self) {
        let now = Instant::now();
        let mut changed = Vec::new();
        for (id, agent) in &mut self.agents {
            if agent.record.kind == AgentKind::Generic && agent.terminal.is_some() && agent.status.is_running() {
                let status = generic_status(agent.last_output, now);
                if status != agent.status {
                    agent.status = status;
                    changed.push(*id);
                }
            }
        }
        for id in changed {
            self.announce(id);
        }

        let mut screens: HashMap<AgentId, Screen> = HashMap::new();
        for client in self.clients.values_mut() {
            let Some(sub) = client.subscription.as_mut() else {
                continue;
            };
            let Some(agent) = self.agents.get(&sub.agent) else {
                continue;
            };
            if !agent.dirty && sub.last.is_some() {
                continue;
            }
            let Some(terminal) = agent.terminal.as_ref() else {
                continue;
            };
            let screen = screens.entry(sub.agent).or_insert_with(|| terminal.screen());
            if let Some(frame) = screen.diff(sub.last.as_ref(), sub.agent) {
                let _ = client.tx.send(ServerMessage::Frame(frame));
            }
            sub.last = Some(screen.clone());
        }
        for agent in self.agents.values_mut() {
            agent.dirty = false;
        }
    }
}
```

```rust
use std::collections::HashMap;
use std::path::Path;
use std::process::{Command, Stdio};
use std::sync::{Arc, Mutex};
use std::time::Duration;

use anyhow::Context;
use protocol::{
    ClientMessage, PROTOCOL_VERSION, Request, Response, ServerMessage, StatePaths, read_message, write_message,
};
use tokio::net::UnixStream;
use tokio::net::unix::OwnedWriteHalf;
use tokio::sync::{mpsc, oneshot};

const TERMINAL_VARS: [&str; 13] = [
    "TMUX",
    "TMUX_PANE",
    "TERM_PROGRAM",
    "TERM_PROGRAM_VERSION",
    "TERM_SESSION_ID",
    "ITERM_SESSION_ID",
    "KITTY_WINDOW_ID",
    "KITTY_PID",
    "WEZTERM_PANE",
    "WEZTERM_UNIX_SOCKET",
    "ALACRITTY_WINDOW_ID",
    "GHOSTTY_RESOURCES_DIR",
    "VSCODE_INJECTION",
];

type Pending = Arc<Mutex<HashMap<u64, oneshot::Sender<Result<Response, String>>>>>;

pub struct Client {
    write: OwnedWriteHalf,
    next_id: u64,
    pending: Pending,
    events: mpsc::UnboundedReceiver<ServerMessage>,
    reader: tokio::task::JoinHandle<()>,
}

impl Drop for Client {
    fn drop(&mut self) {
        self.reader.abort();
    }
}

impl Client {
    pub async fn connect(paths: &StatePaths) -> anyhow::Result<Client> {
        let socket = paths.socket();
        let stream = UnixStream::connect(&socket)
            .await
            .with_context(|| format!("connecting to {}", socket.display()))?;
        let (mut read, mut write) = stream.into_split();
        let welcome = tokio::time::timeout(Duration::from_secs(2), read_message::<_, ServerMessage>(&mut read))
            .await
            .context("daemon did not greet in time")??;
        match welcome {
            Some(ServerMessage::Welcome { protocol_version, .. }) if protocol_version == PROTOCOL_VERSION => {}
            Some(ServerMessage::Welcome { protocol_version, daemon_version }) => anyhow::bail!(
                "daemon {daemon_version} speaks protocol {protocol_version}, this client speaks {PROTOCOL_VERSION}; \
                 stop it with `lazyagents shutdown` and retry"
            ),
            other => anyhow::bail!("unexpected greeting from daemon: {other:?}"),
        }
        write_message(&mut write, &ClientMessage::Hello { protocol_version: PROTOCOL_VERSION }).await?;

        let pending: Pending = Arc::default();
        let (events_tx, events) = mpsc::unbounded_channel();
        let reader_pending = Arc::clone(&pending);
        let reader = tokio::spawn(async move {
            while let Ok(Some(message)) = read_message::<_, ServerMessage>(&mut read).await {
                match message {
                    ServerMessage::Response { id, result } => {
                        let waiter = reader_pending.lock().ok().and_then(|mut p| p.remove(&id));
                        if let Some(waiter) = waiter {
                            let _ = waiter.send(result);
                        }
                    }
                    other => {
                        if events_tx.send(other).is_err() {
                            break;
                        }
                    }
                }
            }
        });
        Ok(Client { write, next_id: 1, pending, events, reader })
    }

    pub async fn connect_or_spawn(paths: &StatePaths, exe: &Path) -> anyhow::Result<Client> {
        match Client::connect(paths).await {
            Ok(client) => return Ok(client),
            Err(e) if e.to_string().contains("protocol") => return Err(e),
            Err(_) => {}
        }
        std::fs::create_dir_all(paths.dir())?;
        spawn_daemon(paths, exe).context("starting the daemon")?;
        let deadline = tokio::time::Instant::now() + Duration::from_secs(5);
        loop {
            match Client::connect(paths).await {
                Ok(client) => return Ok(client),
                Err(e) if tokio::time::Instant::now() >= deadline => {
                    return Err(e.context(format!("daemon did not start; see {}", paths.log_file().display())));
                }
                Err(_) => tokio::time::sleep(Duration::from_millis(25)).await,
            }
        }
    }

    pub async fn request(&mut self, request: Request) -> anyhow::Result<Response> {
        let id = self.next_id;
        self.next_id += 1;
        let (tx, rx) = oneshot::channel();
        self.pending
            .lock()
            .map_err(|_| anyhow::anyhow!("client state poisoned"))?
            .insert(id, tx);
        write_message(&mut self.write, &ClientMessage::Request { id, request }).await?;
        match rx.await {
            Ok(Ok(response)) => Ok(response),
            Ok(Err(message)) => Err(anyhow::anyhow!(message)),
            Err(_) => anyhow::bail!("daemon closed the connection"),
        }
    }

    pub async fn next_event(&mut self) -> Option<ServerMessage> {
        self.events.recv().await
    }
}

pub fn spawn_daemon(paths: &StatePaths, exe: &Path) -> std::io::Result<()> {
    use std::os::unix::process::CommandExt;

    let mut command = Command::new(exe);
    command
        .arg("daemon")
        .env("LAZYAGENTS_STATE_DIR", paths.dir())
        .stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::null())
        .process_group(0);
    for var in TERMINAL_VARS {
        command.env_remove(var);
    }
    command.spawn().map(drop)
}
```

```rust
    Restart { agent: String },

    Generic,
```

```rust
use protocol::{AgentId, ClientMessage, HookKind, PROTOCOL_VERSION, Request, ServerMessage, read_message, write_message};
use tokio::net::UnixStream;
use uuid::Uuid;

const BUDGET: Duration = Duration::from_millis(200);

pub fn run(event: &str) {
    let Some(kind) = HookKind::from_name(event) else {
        return;
    };
    let mut payload = String::new();
    let _ = std::io::stdin().read_to_string(&mut payload);
    let session_id = serde_json::from_str::<serde_json::Value>(&payload)
        .ok()
        .and_then(|value| value.get("session_id")?.as_str().map(str::to_owned));
    let agent = std::env::var("LAZYAGENTS_AGENT_ID").ok().and_then(|s| s.parse::<Uuid>().ok());
    let socket = std::env::var_os("LAZYAGENTS_SOCKET");
    let (Some(agent), Some(socket)) = (agent, socket) else {
        return;
    };
    let Ok(runtime) = tokio::runtime::Builder::new_current_thread().enable_all().build() else {
        return;
    };
    let _ = runtime.block_on(tokio::time::timeout(
        BUDGET,
        send(PathBuf::from(socket), AgentId(agent), kind, session_id),
    ));
}

async fn send(socket: PathBuf, agent: AgentId, kind: HookKind, session_id: Option<String>) -> std::io::Result<()> {
    let mut stream = UnixStream::connect(socket).await?;
    let _welcome: Option<ServerMessage> = read_message(&mut stream).await?;
    write_message(&mut stream, &ClientMessage::Hello { protocol_version: PROTOCOL_VERSION }).await?;
    let request = Request::Hook { id: agent, kind, session_id };
    write_message(&mut stream, &ClientMessage::Request { id: 1, request }).await?;
    let _reply: Option<ServerMessage> = read_message(&mut stream).await?;
    Ok(())
```

```rust
use std::path::{Path, PathBuf};
use std::time::Duration;

use anyhow::{Context, anyhow, bail};
use client::Client;
use protocol::{AgentInfo, AgentKind, CreateAgent, Project, Request, Response, StatePaths};

use crate::{Command, Kind, ProjectCommand};

const DEFAULT_COLS: u16 = 120;
const DEFAULT_ROWS: u16 = 40;

pub async fn run(command: Command) -> anyhow::Result<()> {
    let paths = StatePaths::from_env()?;
    if matches!(command, Command::Shutdown) {
        return shutdown(&paths).await;
    }
    let exe = std::env::current_exe().context("locating the lazyagents binary")?;
    let mut client = Client::connect_or_spawn(&paths, &exe).await?;
    match command {
        Command::Ls => {
            let (projects, agents) = snapshot(&mut client).await?;
            print!("{}", format_ls(&projects, &agents));
        }
        Command::Project(ProjectCommand::Add { path, name }) => {
            let path = match path {
                Some(path) => path,
                None => std::env::current_dir()?,
            };
            let project = add_project(&mut client, path, name).await?;
            println!("added {} ({})", project.name, project.path.display());
        }
        Command::Project(ProjectCommand::Rm { project }) => {
            let (projects, _) = snapshot(&mut client).await?;
            let project = resolve_project(&projects, &project)?;
            client.request(Request::RemoveProject { id: project.id }).await?;
            println!("removed project {}", project.name);
        }
        Command::New { name, project, kind, command } => {
            let (projects, _) = snapshot(&mut client).await?;
            let project = match project {
                Some(query) => resolve_project(&projects, &query)?,
                None => {
                    let cwd = std::env::current_dir()?.canonicalize()?;
                    match containing_project(&projects, &cwd) {
                        Some(project) => project,
                        None => add_project(&mut client, cwd, None).await?,
                    }
                }
            };
            let kind = match (kind, command.is_empty()) {
                (Some(Kind::Claude), _) | (None, true) => AgentKind::Claude,
                (Some(Kind::Generic), _) | (None, false) => AgentKind::Generic,
            };
            let request = Request::CreateAgent(CreateAgent {
                project: project.id,
                name,
                kind,
                command,
                cols: DEFAULT_COLS,
                rows: DEFAULT_ROWS,
            });
            let info = expect_agent(client.request(request).await?)?;
            println!("started {}", info.name);
        }
        Command::Kill { agent } => {
            let info = find_agent(&mut client, &agent).await?;
            client.request(Request::KillAgent { id: info.id }).await?;
            println!("stopped {}", info.name);
        }
        Command::Restart { agent } => {
            let info = find_agent(&mut client, &agent).await?;
            let request = Request::RestartAgent { id: info.id, cols: DEFAULT_COLS, rows: DEFAULT_ROWS };
            client.request(request).await?;
            println!("restarted {}", info.name);
        }
        Command::Rm { agent } => {
            let info = find_agent(&mut client, &agent).await?;
            client.request(Request::RemoveAgent { id: info.id }).await?;
            println!("removed {}", info.name);
        }
        Command::Rename { agent, name } => {
            let info = find_agent(&mut client, &agent).await?;
            let renamed = expect_agent(client.request(Request::RenameAgent { id: info.id, name }).await?)?;
            println!("renamed {} to {}", info.name, renamed.name);
        }
        Command::Daemon | Command::Hook { .. } | Command::Shutdown => unreachable!("dispatched in main"),
    }
    Ok(())
}

async fn shutdown(paths: &StatePaths) -> anyhow::Result<()> {
    let Ok(mut client) = Client::connect(paths).await else {
        println!("daemon is not running");
        return Ok(());
    };
    client.request(Request::Shutdown).await?;
    let socket = paths.socket();
    for _ in 0..60 {
        if !socket.exists() {
            break;
        }
        tokio::time::sleep(Duration::from_millis(50)).await;
    }
    if socket.exists() {
        bail!("daemon did not stop within 3s");
    }
    println!("daemon stopped");
    Ok(())
}

async fn snapshot(client: &mut Client) -> anyhow::Result<(Vec<Project>, Vec<AgentInfo>)> {
    let Response::Projects(projects) = client.request(Request::ListProjects).await? else {
        bail!("unexpected reply to ListProjects");
    };
    let Response::Agents(agents) = client.request(Request::ListAgents).await? else {
        bail!("unexpected reply to ListAgents");
    };
    Ok((projects, agents))
}

async fn add_project(client: &mut Client, path: PathBuf, name: Option<String>) -> anyhow::Result<Project> {
    match client.request(Request::AddProject { path, name }).await? {
        Response::Project(project) => Ok(project),
        other => bail!("unexpected reply to AddProject: {other:?}"),
    }
}

async fn find_agent(client: &mut Client, query: &str) -> anyhow::Result<AgentInfo> {
    let (projects, agents) = snapshot(client).await?;
    resolve_agent(&projects, &agents, query)
}

fn expect_agent(response: Response) -> anyhow::Result<AgentInfo> {
    match response {
        Response::Agent(info) => Ok(info),
        other => bail!("unexpected reply: {other:?}"),
    }
}

fn containing_project(projects: &[Project], cwd: &Path) -> Option<Project> {
    projects
        .iter()
        .filter(|p| cwd.starts_with(&p.path))
        .max_by_key(|p| p.path.components().count())
        .cloned()
}

fn resolve_project(projects: &[Project], query: &str) -> anyhow::Result<Project> {
    if let Some(project) = projects.iter().find(|p| p.name == query) {
        return Ok(project.clone());
    }
    let path = Path::new(query).canonicalize().ok();
    projects
        .iter()
        .find(|p| Some(&p.path) == path.as_ref())
        .cloned()
        .ok_or_else(|| anyhow!("no project named or located at {query}"))
}

fn resolve_agent(projects: &[Project], agents: &[AgentInfo], query: &str) -> anyhow::Result<AgentInfo> {
    if let Some(agent) = agents.iter().find(|a| a.id.to_string() == query) {
        return Ok(agent.clone());
    }
    if let Some((project, name)) = query.split_once('/') {
        let project = resolve_project(projects, project)?;
        return agents
            .iter()
            .find(|a| a.project == project.id && a.name == name)
            .cloned()
            .ok_or_else(|| anyhow!("no agent {name} in {}", project.name));
    }
    let by_name: Vec<&AgentInfo> = agents.iter().filter(|a| a.name == query).collect();
    match by_name.as_slice() {
        [one] => return Ok((*one).clone()),
        [] => {}
        _ => bail!("{query} is ambiguous; use <project>/{query}"),
    }
    if query.len() >= 4 && query.chars().all(|c| c.is_ascii_hexdigit() || c == '-') {
        let by_prefix: Vec<&AgentInfo> = agents.iter().filter(|a| a.id.to_string().starts_with(query)).collect();
        if let [one] = by_prefix.as_slice() {
            return Ok((*one).clone());
        }
    }
    bail!("no agent matches {query}")
}

fn format_ls(projects: &[Project], agents: &[AgentInfo]) -> String {
    if projects.is_empty() {
        return "no projects yet; run lazyagents new <name> inside a repo\n".to_string();
    }
    let width = agents.iter().map(|a| a.name.len()).max().unwrap_or(0);
    let mut out = String::new();
    for project in projects {
        out.push_str(&format!("{}  {}\n", project.name, project.path.display()));
        for agent in agents.iter().filter(|a| a.project == project.id) {
            let command = if agent.command.is_empty() { "claude".to_string() } else { agent.command.join(" ") };
            out.push_str(&format!("  {:width$}  {:12}  {command}\n", agent.name, agent.status.label()));
        }
    }
    out
}
```

```markdown
# 0006. Restart resumes only sessions that received a prompt

Date: 2026-10-15
Status: Accepted

## Context

ADR 0003 starts Claude agents with `--session-id <uuid>` and restarts them with `--resume <uuid>`. A session that never received a prompt may not exist on disk, so `--resume` on it can fail. `/clear` also starts a new session id inside the same Claude process.

## Decision

The daemon marks an agent `resumable` when its `UserPromptSubmit` hook fires. Restart passes `--resume` only for resumable agents; otherwise it starts a fresh session id. A `SessionStart` hook carrying a different session id replaces the stored one and clears `resumable`. `PostToolUse` maps to Working, so the status leaves "needs input" once an approved tool finishes.

## Alternatives

- Always `--resume`: fails for agents restarted before their first prompt.
- `--continue`: picks the most recent session in the directory, which is wrong when two agents share a directory.

## Consequences

Restarting an agent that never got a prompt gives a fresh session, which loses nothing. Status depends on hooks firing; agents whose Claude Code ignores `--settings` hooks stay in `starting`.
```

# TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the spike with the real lazygit-style TUI. Running `lazyagents` with no arguments opens a sidebar of projects and agents with live status. The main pane holds the selected agent's interactive terminal, streamed from the daemon. Popups cover new, stop, restart, remove and rename for agents, adding projects, help, and stopping the daemon. The plan starts by closing the daemon gaps parked in plan 2.

**Architecture:** The UI is driven by a pure model. The `tui` crate keeps all UI state in `App`, which consumes `ServerMessage`s, daemon responses and key, paste and wheel events, and returns `Effect`s (requests to send, quit). This makes the behaviour unit-testable without a terminal. `ui.rs` draws an `App` into a ratatui `Frame`, tested with `TestBackend`. `connection.rs` owns the `client::Client` in one task, which keeps requests cancel-safe. `run.rs` wires the crossterm input thread, the connection, signals and the redraw loop, and restores the terminal on every exit path. The daemon keeps everything authoritative; the TUI holds no agent state of its own.

**Tech Stack:** Rust 2024; ratatui 0.30.2 with crossterm 0.29 through `ratatui::crossterm` (the vendored crossterm with the dead-tty fix applies); tokio 1.53.3 (`signal`, `io-std` already enabled); the existing `protocol`, `client` and `daemon` crates; rustix 1.1.5 (process); the tmux harness for end-to-end runs.

**Spec:** `docs/superpowers/specs/2026-10-15-lazyagents-design.md` (sections 3, 4, 7). Decisions: ADR 0002 (embedded pane), 0005 (dead-tty fix) and 0006 (resume rules).

**Scope:** Plan 3 of 4. Plan 4 covers worktrees and the `D` diff view, the config file with configurable keybindings and presets, and text selection and copy. Keyboard scroll mode also moves to plan 4; mouse-wheel scrollback ships here.

## Global Constraints

- All tooling comes from the nix dev shell. Run every cargo, just or git-commit command as `nix develop -c <cmd>`.
- Rust edition 2024. `unsafe_code = "forbid"`, so there is no `std::env::set_var`/`remove_var`; pass env to child `Command`s instead. Clippy runs with `-D warnings`.
- Pinned workspace dependencies only. `Cargo.lock` is committed, and `just` recipes use `--locked`.
- Conventional Commits:
  - types: `feat fix docs refactor test chore build ci perf`
  - scopes: `protocol daemon tui cli client docs nix repo spike`
  - the first line is at most 72 characters; count it.
- Comments: none by default; write one only for a non-obvious invariant. Docs describe the system as it is and never narrate changes.
- Tests and dev runs use a temp `LAZYAGENTS_STATE_DIR`. `~/.local/state/lazyagents` belongs to the user's real agents.
- No test leaves a daemon, agent or TUI process running, even on failure. Kill only exact pids your test recorded, never by broad pattern.
- The tmux harness (`scripts/tmux-harness.sh`) uses only its private server.
- The TUI must exit when its terminal disappears, even if SIGHUP and SIGTERM are ignored (ADR 0005).
- The terminal must be restored on every exit: raw mode, alternate screen, mouse capture, bracketed paste and keyboard-enhancement flags. That includes errors, the daemon going away, signals and panics.
- If plan code fails to compile against a real crate API, make the minimal correction and record it. Test expectations do not change; report a test you believe is wrong.

## Review Focus

1. **The terminal disappears.** If the tmux pane or window is closed, the TUI must exit and not spin, even when it never gets SIGHUP or SIGTERM. Test: Task 7 `scripts/test-tui-hangup.sh`.
2. **Typing in the pane must never trigger sidebar commands.** With the pane focused, `q`, `x`, `d` and `n` go to the agent. Tests: Task 4 `pane_focus_sends_letters_to_the_agent`, `pane_focus_never_quits`.
3. **Selection stays stable while statuses re-sort.** When an agent moves to the top because it needs input, the selected agent stays selected and the pane keeps showing it. Test: Task 3 `selection_follows_the_agent_when_sorting_changes`.
4. **The daemon stops while the TUI is open.** The TUI exits with a message and a restored terminal; it does not hang. Tests: Task 6 `connection_reports_closed_when_the_daemon_stops`, and the Task 7 smoke script step that shuts the daemon down underneath a running TUI.
5. **Orphans.** Processes an agent leaves in its own process group with SIGHUP ignored (`nohup`), and detached descendants of an agent that crashed, must not outlive the agent. Tests: Task 1 `kill_stops_a_nohup_orphan_in_the_agent_group`, `exited_agent_leaves_no_detached_descendants`.

### Task 1: Close the daemon's process-lifecycle gaps

**Files:**
- Modify: `crates/daemon/src/reap.rs`, `crates/daemon/src/server.rs`, `crates/client/src/lib.rs`
- Test: `crates/daemon/tests/server.rs`, `crates/daemon/src/reap.rs` (unit), `crates/client/tests/client.rs`

**Interfaces:**
- Consumes: the existing `reap::{terminate_tree, descendants}`, `Terminal::pid()`, `InstanceLock`, and `client::daemon_pid`.
- Produces:
  - `reap::terminate_tree(roots: &[u32], grace: Duration)`. Its contract now covers each root's process group as well as the tree: on top of the existing behaviour it also sends SIGTERM to each root's group. It waits until both every tree pid and every root group are gone; `kill(-root, 0)` failing means the group is gone. It takes a fresh descendant snapshot before the SIGKILL pass and SIGKILLs every survivor and group.
  - `reap::Tracked { pid: u32, start: String }`.
  - `reap::snapshot(root: u32) -> Vec<Tracked>`: the descendants of `root`, each with its start time, from one call to `ps -A -o pid=,ppid=,lstart=`. The start time is the text after the second field.
  - `reap::terminate_tracked(tracked: &[Tracked], grace: Duration)`: signals only the processes whose pid is alive **and** whose current start time equals the recorded one. It sends SIGTERM, waits up to `grace`, then sends SIGKILL.
  - `client::daemon_pid(&StatePaths) -> Option<u32>`: returns `None` unless the lock file is currently locked by another process. It probes with `File::try_lock`: if it acquires the lock, it releases it and returns `None`.

### Task 3: TUI model

**Files:**
- Modify: `crates/tui/Cargo.toml`, `crates/tui/src/lib.rs`

**Interfaces:**
- Produces, in `tui::app`, all `pub`:
  - Enums:
    - `Focus { Projects, Agents, Pane }`
    - `Preset { Claude, Shell, Custom }`, with `label()`, `next()` and `previous()`

    - `Confirmed { Kill(AgentId), Remove(AgentId), StopDaemon }`
    - `Popup { Help, NewAgent(NewAgentForm), Rename { agent: AgentId, input: String }, AddProject { input: String }, Confirm { prompt: String, action: Confirmed } }`
    - `Effect { Send(Request), Quit, StopDaemonAndQuit }`
  - `NewAgentForm { name: String, preset: Preset, command: String, field: Field }`
  - `App`:
    - Fields (pub): `projects`, `agents`, `focus`, `popup`, `project_index`, `agent_index`, `subscribed: Option<AgentId>`, `screen: Screen`, `pane_size: Option<(u16, u16)>`, `message: Option<(String, Instant)>`
    - Private fields: `pending_select: Option<(ProjectId, String)>`, `cwd: PathBuf`, `shell: String`
    - Methods: `App::new(cwd, shell)`, `selected_project()`, `visible_agents() -> Vec<&AgentInfo>`, `selected_agent()`, `attention(ProjectId) -> usize`, `current_message(now) -> Option<&str>`, `fail(msg)`, `apply_server(ServerMessage) -> Vec<Effect>`, `apply_response(Response) -> Vec<Effect>`, `set_pane_size(cols, rows) -> Vec<Effect>`
  - The key, paste and wheel handlers are added in Task 4.
- Rules:
  - `visible_agents` returns the selected project's agents sorted so `NeedsInput` comes first, then by name.
  - The selection is identified by `AgentId`. When the order changes, the same agent stays selected.
  - When the selected agent changes, the app subscribes to it: `Subscribe`, plus `Resize` if the pane size is known and the agent is running. Selecting nothing sends `Unsubscribe`. The mirrored `screen` is reset whenever the subscription changes.
  - Frames for other agents are ignored.
  - `pending_select` makes a just-created agent the selection and focuses the pane once it appears, whether through `AgentUpdated` or the response.
  - Indices clamp when items disappear. Pane focus falls back to `Agents` when no agent is selected.

```rust
#[cfg(test)]
pub(crate) mod tests {
    use super::*;
    use protocol::{AgentKind, Cell, Frame, Row};

    pub(crate) fn project(name: &str) -> Project {
        Project { id: ProjectId::random(), name: name.into(), path: format!("/p/{name}").into() }
    }

    pub(crate) fn agent(project: &Project, name: &str, status: Status) -> AgentInfo {
        AgentInfo {
            id: AgentId::random(),
            project: project.id,
            name: name.into(),
            kind: AgentKind::Generic,
            command: vec!["sh".into()],
            cwd: project.path.clone(),
            status,
        }
    }

    pub(crate) fn loaded(projects: Vec<Project>, agents: Vec<AgentInfo>) -> (App, Vec<Effect>) {
        let mut app = App::new("/work".into(), "/bin/sh".into());
        let mut effects = app.apply_response(Response::Projects(projects));
        effects.extend(app.apply_response(Response::Agents(agents)));
        (app, effects)
    }

    #[test]
    fn loading_selects_and_subscribes_to_the_first_agent() {
        let p = project("p");
        let a = agent(&p, "alpha", Status::Idle);
        let (app, effects) = loaded(vec![p], vec![a.clone()]);
        assert_eq!(app.selected_agent().map(|x| x.id), Some(a.id));
        assert_eq!(effects, vec![Effect::Send(Request::Subscribe { id: a.id })]);
        assert_eq!(app.subscribed, Some(a.id));
    }

    #[test]
    fn needs_input_sorts_first_within_the_project() {
        let p = project("p");
        let a = agent(&p, "alpha", Status::Idle);
        let b = agent(&p, "beta", Status::NeedsInput);
        let (app, _) = loaded(vec![p], vec![a, b]);
        let names: Vec<&str> = app.visible_agents().iter().map(|x| x.name.as_str()).collect();
        assert_eq!(names, ["beta", "alpha"]);
    }

    #[test]
    fn selection_follows_the_agent_when_sorting_changes() {
        let p = project("p");
        let a = agent(&p, "alpha", Status::Idle);
        let mut b = agent(&p, "beta", Status::Idle);
        let (mut app, _) = loaded(vec![p], vec![a.clone(), b.clone()]);
        app.agent_index = 1;
        let _ = app.apply_server(ServerMessage::AgentUpdated(b.clone()));
        assert_eq!(app.selected_agent().map(|x| x.id), Some(b.id));
        let before = app.subscribed;
        b.status = Status::NeedsInput;
        let effects = app.apply_server(ServerMessage::AgentUpdated(b.clone()));
        assert_eq!(app.selected_agent().map(|x| x.id), Some(b.id));
        assert_eq!(app.subscribed, before);
        assert!(effects.is_empty());
        let _ = a;
    }

    #[test]
    fn attention_counts_agents_needing_input() {
        let p = project("p");
        let q = project("q");
        let (app, _) = loaded(
            vec![p.clone(), q.clone()],
            vec![agent(&p, "a", Status::NeedsInput), agent(&p, "b", Status::NeedsInput), agent(&q, "c", Status::Idle)],
        );
        assert_eq!(app.attention(p.id), 2);
        assert_eq!(app.attention(q.id), 0);
    }

    #[test]
    fn frames_for_other_agents_are_ignored() {
        let p = project("p");
        let a = agent(&p, "alpha", Status::Idle);
        let (mut app, _) = loaded(vec![p], vec![a.clone()]);
        let cells = vec![Cell { text: "x".into(), ..Cell::default() }];
        let frame = |agent| Frame { agent, cols: 1, rows: 1, full: true, lines: vec![Row { index: 0, cells: cells.clone() }], cursor: None };
        let _ = app.apply_server(ServerMessage::Frame(frame(AgentId::random())));
        assert_eq!(app.screen.text(), "");
        let _ = app.apply_server(ServerMessage::Frame(frame(a.id)));
        assert_eq!(app.screen.text(), "x");
    }

    #[test]
    fn removing_the_selected_agent_moves_the_subscription() {
        let p = project("p");
        let a = agent(&p, "alpha", Status::Idle);
        let b = agent(&p, "beta", Status::Idle);
        let (mut app, _) = loaded(vec![p], vec![a.clone(), b.clone()]);
        app.focus = Focus::Pane;
        let effects = app.apply_server(ServerMessage::AgentRemoved(a.id));
        assert_eq!(app.subscribed, Some(b.id));
        assert_eq!(effects, vec![Effect::Send(Request::Subscribe { id: b.id })]);
        let effects = app.apply_server(ServerMessage::AgentRemoved(b.id));
        assert_eq!(app.subscribed, None);
        assert_eq!(effects, vec![Effect::Send(Request::Unsubscribe)]);
        assert_eq!(app.focus, Focus::Agents);
    }

    #[test]
    fn pane_size_resizes_running_agents_only_when_it_changes() {
        let p = project("p");
        let a = agent(&p, "alpha", Status::Idle);
        let (mut app, _) = loaded(vec![p.clone()], vec![a.clone()]);
        assert_eq!(app.set_pane_size(80, 20), vec![Effect::Send(Request::Resize { id: a.id, cols: 80, rows: 20 })]);
        assert!(app.set_pane_size(80, 20).is_empty());
        let stopped = AgentInfo { status: Status::Stopped, ..a.clone() };
        let _ = app.apply_server(ServerMessage::AgentUpdated(stopped));
        assert!(app.set_pane_size(90, 20).is_empty());
    }

    #[test]
    fn subscribing_sends_the_known_pane_size() {
        let p = project("p");
        let a = agent(&p, "alpha", Status::Idle);
        let mut app = App::new("/work".into(), "/bin/sh".into());

    pub fn new(cwd: PathBuf, shell: String) -> Self {
        Self {
            projects: Vec::new(),
            agents: Vec::new(),
            focus: Focus::Agents,
            popup: None,
            project_index: 0,
            agent_index: 0,

            message: None,
            pending_select: None,
            cwd,
            shell,
        }
    }

    pub fn selected_project(&self) -> Option<&Project> {
        self.projects.get(self.project_index)
    }

    pub fn visible_agents(&self) -> Vec<&AgentInfo> {
        let Some(project) = self.selected_project() else {
            return Vec::new();
        };
        let mut agents: Vec<&AgentInfo> = self.agents.iter().filter(|a| a.project == project.id).collect();
        agents.sort_by(|a, b| {
            (a.status != Status::NeedsInput, &a.name).cmp(&(b.status != Status::NeedsInput, &b.name))
        });
        agents
    }

    pub fn selected_agent(&self) -> Option<&AgentInfo> {
        self.visible_agents().get(self.agent_index).copied()
    }

    pub fn attention(&self, project: ProjectId) -> usize {
        self.agents
            .iter()
            .filter(|a| a.project == project && a.status == Status::NeedsInput)
            .count()
    }

    pub fn current_message(&self, now: Instant) -> Option<&str> {
        self.message
            .as_ref()
            .filter(|(_, at)| now.saturating_duration_since(*at) < MESSAGE_TTL)
            .map(|(message, _)| message.as_str())

        self.message = Some((message.into(), Instant::now()));

    pub fn apply_server(&mut self, message: ServerMessage) -> Vec<Effect> {
        match message {
            ServerMessage::AgentUpdated(info) => self.upsert_agent(info),
            ServerMessage::AgentRemoved(id) => self.agents.retain(|a| a.id != id),
            ServerMessage::ProjectsChanged(projects) => self.replace_projects(projects),
            ServerMessage::Frame(frame) => {
                if Some(frame.agent) == self.subscribed {
                    self.screen.apply(&frame);
                }
                return Vec::new();
            }
            ServerMessage::Welcome { .. } | ServerMessage::Response { .. } => {}
        }
        self.sync()
    }

    pub fn apply_response(&mut self, response: Response) -> Vec<Effect> {
        match response {
            Response::Projects(projects) => self.replace_projects(projects),
            Response::Agents(agents) => {
                let selected = self.selected_agent().map(|a| a.id);
                self.agents = agents;
                if let Some(id) = selected {
                    self.select_agent(id);
                }
            }
            Response::Project(project) => {
                if !self.projects.iter().any(|p| p.id == project.id) {
                    self.projects.push(project.clone());
                }
                if let Some(index) = self.projects.iter().position(|p| p.id == project.id) {
                    self.project_index = index;
                    self.agent_index = 0;
                }
            }
            Response::Agent(info) => self.upsert_agent(info),
            Response::Ok => {}
        }
        self.sync()
    }

    pub fn set_pane_size(&mut self, cols: u16, rows: u16) -> Vec<Effect> {
        if self.pane_size == Some((cols, rows)) {
            return Vec::new();
        }
        self.pane_size = Some((cols, rows));
        match self.selected_agent() {
            Some(agent) if agent.status.is_running() => {
                vec![Effect::Send(Request::Resize { id: agent.id, cols, rows })]
            }
            _ => Vec::new(),
        }
    }

    fn replace_projects(&mut self, projects: Vec<Project>) {
        let selected = self.selected_project().map(|p| p.id);
        self.projects = projects;
        if let Some(index) = selected.and_then(|id| self.projects.iter().position(|p| p.id == id)) {
            self.project_index = index;
        }
    }

    fn upsert_agent(&mut self, info: AgentInfo) {
        let selected = self.selected_agent().map(|a| a.id);
        match self.agents.iter_mut().find(|a| a.id == info.id) {
            Some(existing) => *existing = info.clone(),
            None => self.agents.push(info.clone()),
        }
        let wanted = self
            .pending_select
            .as_ref()
            .is_some_and(|(project, name)| *project == info.project && *name == info.name);
        if wanted {
            self.pending_select = None;
            self.select_agent(info.id);
            self.focus = Focus::Pane;
        } else if let Some(id) = selected {
            self.select_agent(id);
        }
    }

    fn select_agent(&mut self, id: AgentId) {
        let Some(project) = self.agents.iter().find(|a| a.id == id).map(|a| a.project) else {
            return;
        };
        if let Some(index) = self.projects.iter().position(|p| p.id == project) {
            self.project_index = index;
        }
        if let Some(index) = self.visible_agents().iter().position(|a| a.id == id) {
            self.agent_index = index;
        }
    }

    fn sync(&mut self) -> Vec<Effect> {
        self.project_index = self.project_index.min(self.projects.len().saturating_sub(1));
        let count = self.visible_agents().len();
        self.agent_index = self.agent_index.min(count.saturating_sub(1));
        let wanted = self.selected_agent().map(|a| (a.id, a.status.is_running()));
        if wanted.is_none() && self.focus == Focus::Pane {
            self.focus = Focus::Agents;
        }
        if wanted.map(|(id, _)| id) == self.subscribed {
            return Vec::new();
        }
        self.subscribed = wanted.map(|(id, _)| id);
        self.screen = Screen::blank(0, 0);
        match wanted {
            Some((id, running)) => {
                let mut effects = vec![Effect::Send(Request::Subscribe { id })];
                if let (true, Some((cols, rows))) = (running, self.pane_size) {
                    effects.push(Effect::Send(Request::Resize { id, cols, rows }));
                }
                effects
            }
            None => vec![Effect::Send(Request::Unsubscribe)],
        }
    }
}

use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};

pub fn to_protocol(key: &KeyEvent) -> Option<Key> {
    let code = match key.code {
        KeyCode::Char(c) => Code::Char(c),
        KeyCode::Enter => Code::Enter,
        KeyCode::Tab => Code::Tab,
        KeyCode::BackTab => Code::BackTab,
        KeyCode::Backspace => Code::Backspace,
        KeyCode::Esc => Code::Esc,
        KeyCode::Up => Code::Up,
        KeyCode::Down => Code::Down,
        KeyCode::Left => Code::Left,
        KeyCode::Right => Code::Right,
        KeyCode::Home => Code::Home,
        KeyCode::End => Code::End,
        KeyCode::Insert => Code::Insert,
        KeyCode::Delete => Code::Delete,
        KeyCode::PageUp => Code::PageUp,
        KeyCode::PageDown => Code::PageDown,
        KeyCode::F(n) => Code::F(n),
        _ => return None,
    };
    let mods = Modifiers {
        shift: key.modifiers.contains(KeyModifiers::SHIFT),
        alt: key.modifiers.contains(KeyModifiers::ALT),
        ctrl: key.modifiers.contains(KeyModifiers::CONTROL),
    };
    Some(Key::new(code, mods))
}

pub fn is_detach(key: &KeyEvent) -> bool {
    key.modifiers.contains(KeyModifiers::CONTROL) && matches!(key.code, KeyCode::Char(']') | KeyCode::Char('5'))
}

pub fn cycle_step(key: &KeyEvent) -> Option<i32> {
    if !key.modifiers.contains(KeyModifiers::ALT) {
        return None;
    }
    match key.code {
        KeyCode::Char('[') => Some(-1),
        KeyCode::Char(']') => Some(1),
        _ => None,
    }
}

const WHEEL_LINES: i32 = 3;

#[derive(Debug, PartialEq, Eq)]
enum Edit {
    Continue,
    Submit,
    Cancel,
}

fn edit(input: &mut String, key: &KeyEvent) -> Edit {
    let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
    match key.code {
        KeyCode::Enter => Edit::Submit,
        KeyCode::Esc => Edit::Cancel,
        KeyCode::Backspace => {
            input.pop();
            Edit::Continue
        }
        KeyCode::Char('u') if ctrl => {
            input.clear();
            Edit::Continue
        }
        KeyCode::Char(c) if !ctrl => {
            input.push(c);
            Edit::Continue
        }
        _ => Edit::Continue,
    }
}

    pub fn on_key(&mut self, key: KeyEvent) -> Vec<Effect> {
        if key.kind == KeyEventKind::Release {
            return Vec::new();
        }
        if self.popup.is_some() {
            return self.on_popup_key(key);
        }
        match self.focus {
            Focus::Pane => self.on_pane_key(key),
            Focus::Projects | Focus::Agents => self.on_sidebar_key(key),
        }
    }

    pub fn on_paste(&mut self, text: String) -> Vec<Effect> {
        if self.popup.is_none() {
            return match (self.focus, self.selected_agent()) {
                (Focus::Pane, Some(agent)) => {
                    vec![Effect::Send(Request::Input { id: agent.id, event: InputEvent::Paste(text) })]
                }
                _ => Vec::new(),
            };
        }
        let line = text.lines().next().unwrap_or_default().to_string();
        match &mut self.popup {
            Some(Popup::Rename { input, .. } | Popup::AddProject { input }) => input.push_str(&line),
            Some(Popup::NewAgent(form)) => match form.field {
                Field::Name => form.name.push_str(&line),
                Field::Command => form.command.push_str(&line),
                Field::Preset => {}
            },
            Some(Popup::Help | Popup::Confirm { .. }) | None => {}
        }
        Vec::new()
    }

    pub fn on_wheel(&mut self, up: bool, col: u16, row: u16) -> Vec<Effect> {
        if self.popup.is_some() {
            return Vec::new();
        }
        let Some(agent) = self.selected_agent() else {
            return Vec::new();
        };
        let request = if agent.status.is_running() {
            Request::Input { id: agent.id, event: InputEvent::Wheel { up, col, row } }
        } else {
            Request::Scroll { id: agent.id, lines: if up { WHEEL_LINES } else { -WHEEL_LINES } }
        };
        vec![Effect::Send(request)]
    }

    fn on_pane_key(&mut self, key: KeyEvent) -> Vec<Effect> {
        let Some(id) = self.selected_agent().map(|a| a.id) else {
            self.focus = Focus::Agents;
            return Vec::new();
        };
        if keys::is_detach(&key) {
            self.focus = Focus::Agents;
            return Vec::new();
        }
        if let Some(step) = keys::cycle_step(&key) {
            self.move_agent(step);
            return self.sync();
        }
        match keys::to_protocol(&key) {
            Some(key) => vec![Effect::Send(Request::Input { id, event: InputEvent::Key(key) })],
            None => Vec::new(),
        }
    }

    fn on_sidebar_key(&mut self, key: KeyEvent) -> Vec<Effect> {
        if key.modifiers.contains(KeyModifiers::CONTROL) {

            command: String::new(),

    fn next_attention(&mut self) {
        let position = |id: ProjectId| self.projects.iter().position(|p| p.id == id);
        let mut ordered: Vec<&AgentInfo> = self.agents.iter().collect();
        ordered.sort_by(|a, b| (position(a.project), &a.name).cmp(&(position(b.project), &b.name)));
        let current = self.selected_agent().map(|a| a.id);
        let start = current
            .and_then(|id| ordered.iter().position(|a| a.id == id))
            .map_or(0, |i| i + 1);
        let next = (0..ordered.len())
            .map(|offset| ordered[(start + offset) % ordered.len()])
            .find(|a| a.status == Status::NeedsInput)
            .map(|a| a.id);
        match next {
            Some(id) => self.select_agent(id),
            None => self.fail("no agent needs input"),
        }
    }

    fn on_popup_key(&mut self, key: KeyEvent) -> Vec<Effect> {
        let Some(popup) = self.popup.take() else {
            return Vec::new();
        };
        match popup {
            Popup::Help => Vec::new(),
            Popup::Confirm { prompt, action } => match key.code {

                    Confirmed::Kill(id) => vec![Effect::Send(Request::KillAgent { id })],
                    Confirmed::Remove(id) => vec![Effect::Send(Request::RemoveAgent { id })],
                    Confirmed::StopDaemon => vec![Effect::StopDaemonAndQuit],
                },
                KeyCode::Char('n') | KeyCode::Esc => Vec::new(),
                _ => {
                    self.popup = Some(Popup::Confirm { prompt, action });
                    Vec::new()
                }
            },
            Popup::Rename { agent, mut input } => match edit(&mut input, &key) {
                Edit::Submit => vec![Effect::Send(Request::RenameAgent { id: agent, name: input.trim().to_string() })],
                Edit::Cancel => Vec::new(),
                Edit::Continue => {
                    self.popup = Some(Popup::Rename { agent, input });
                    Vec::new()
                }
            },
            Popup::AddProject { mut input } => match edit(&mut input, &key) {
                Edit::Submit => vec![Effect::Send(Request::AddProject { path: self.cwd.join(input.trim()), name: None })],
                Edit::Cancel => Vec::new(),
                Edit::Continue => {
                    self.popup = Some(Popup::AddProject { input });
                    Vec::new()
                }
            },
            Popup::NewAgent(form) => self.on_form_key(form, key),
        }
    }

    fn on_form_key(&mut self, mut form: NewAgentForm, key: KeyEvent) -> Vec<Effect> {
        match key.code {
            KeyCode::Esc => return Vec::new(),
            KeyCode::Enter => return self.submit_form(form),
            KeyCode::Tab | KeyCode::Down => form.field = next_field(form.field, form.preset),
            KeyCode::BackTab | KeyCode::Up => form.field = previous_field(form.field, form.preset),
            KeyCode::Left if form.field == Field::Preset => form.preset = form.preset.previous(),
            KeyCode::Right | KeyCode::Char(' ') if form.field == Field::Preset => form.preset = form.preset.next(),
            _ => {
                let target = match form.field {
                    Field::Name => Some(&mut form.name),
                    Field::Command => Some(&mut form.command),
                    Field::Preset => None,
                };
                if let Some(target) = target {
                    edit(target, &key);
                }
            }
        }
        self.popup = Some(Popup::NewAgent(form));
        Vec::new()
    }

    fn submit_form(&mut self, form: NewAgentForm) -> Vec<Effect> {
        let Some(project) = self.selected_project().map(|p| p.id) else {
            return Vec::new();
        };
        let name = form.name.trim().to_string();
        if name.is_empty() {
            self.fail("name the agent first");
            self.popup = Some(Popup::NewAgent(form));
            return Vec::new();
        }
        let (kind, command) = match form.preset {
            Preset::Claude => (AgentKind::Claude, Vec::new()),
            Preset::Shell => (AgentKind::Generic, vec![self.shell.clone()]),
            Preset::Custom => {
                let command = form.command.trim().to_string();
                if command.is_empty() {
                    self.fail("enter a command");
                    self.popup = Some(Popup::NewAgent(form));
                    return Vec::new();
                }
                (AgentKind::Generic, vec!["sh".into(), "-c".into(), command])
            }
        };
        let (cols, rows) = self.pane_size.unwrap_or(DEFAULT_SIZE);
        self.pending_select = Some((project, name.clone()));
        vec![Effect::Send(Request::CreateAgent(CreateAgent { project, name, kind, command, cols, rows }))]
    }
}

fn wrap(index: usize, step: i32, count: usize) -> usize {
    (index as i64 + i64::from(step)).rem_euclid(count as i64) as usize
}

fn next_field(field: Field, preset: Preset) -> Field {
    match (field, preset) {
        (Field::Name, _) => Field::Preset,
        (Field::Preset, Preset::Custom) => Field::Command,
        (Field::Preset, _) | (Field::Command, _) => Field::Name,
    }
}

    match (field, preset) {
        (Field::Name, Preset::Custom) => Field::Command,
        (Field::Name, _) => Field::Preset,
        (Field::Preset, _) => Field::Name,
        (Field::Command, _) => Field::Preset,
    }
}

  - `connection::spawn(client: client::Client) -> (mpsc::UnboundedSender<Request>, mpsc::UnboundedReceiver<Incoming>)`. One task owns the client and loops on a `tokio::select!` of the request receiver and `client.next_event()`. A request is awaited inside the branch body, not as a select future, which keeps it cancel-safe.
    - `Ok(Response::Ok)` is dropped, other responses become `Response`, and errors become `Failed`.
    - An error whose text contains `closed the connection`, or the event stream ending, sends `Closed` and ends the task.
    - The request sender being dropped ends the task.
  - `run::run(paths: StatePaths, exe: PathBuf) -> anyhow::Result<()>`, re-exported as `tui::run`:
    - First, if stdout is not a terminal (`std::io::IsTerminal`), fails with `lazyagents needs an interactive terminal; run lazyagents --help for headless commands`, before connecting or touching any tty.
    - Calls `Client::connect_or_spawn`. A `VersionMismatch` or any other failure is returned before the terminal is touched.
    - Sends `ListProjects` and `ListAgents`.
    - Enters a `TerminalGuard`, which does the following:
      - `ratatui::init()`; bracketed paste and mouse capture; keyboard-enhancement flags `DISAMBIGUATE_ESCAPE_CODES` when supported.
      - A chained panic hook that pops the flags and disables mouse and paste before the previous hook (which restores raw mode and the alternate screen).
      - `Drop` pops the flags, disables mouse and paste, and calls `ratatui::restore()`.
    - Spawns a std thread that loops `crossterm::event::read()`. It forwards Key (non-release), Paste, Mouse (scroll up/down only) and Resize as a `Term` enum over an unbounded channel. On `Err`, which a dead tty now produces through the vendored crossterm, it sends `Term::Gone` and returns.
    - Main loop:
      - Before each draw, compute `ui::areas` from the terminal size and apply `app.set_pane_size(pane_inner)`.
      - Draw when something changed, and on a 250 ms tick so expiring messages clear.
      - Then `select!` over input, connection, SIGHUP/SIGTERM/SIGINT (`tokio::signal::unix`) and the tick.
      - Wheel events inside `pane_inner` become `app.on_wheel(up, col - x, row - y)`.
      - Effects: `Send` → the request channel; `Quit` → leave the loop; `StopDaemonAndQuit` → send `Shutdown`, wait up to 3 s for `Closed`, then leave.
    - `Closed` before quitting: leave the loop and return `Err("the daemon stopped")` after the guard has restored the terminal.
    - `Term::Gone`, or a signal: leave the loop and return `Ok(())`.
  - `lazyagents` with no subcommand runs `tui::run(StatePaths::from_env()?, current_exe()?)` on a multi-thread tokio runtime. All other subcommands are unchanged.

use client::Client;
use protocol::{Request, Response, ServerMessage};
use tokio::sync::mpsc::{self, UnboundedReceiver, UnboundedSender};

#[derive(Debug)]
pub enum Incoming {
    Server(ServerMessage),
    Response(Response),
    Failed(String),
    Closed,
}

pub fn spawn(mut client: Client) -> (UnboundedSender<Request>, UnboundedReceiver<Incoming>) {
    let (requests_tx, mut requests) = mpsc::unbounded_channel::<Request>();
    let (incoming_tx, incoming) = mpsc::unbounded_channel();
    tokio::spawn(async move {
        loop {
            tokio::select! {
                request = requests.recv() => {
                    let Some(request) = request else { break };
                    match client.request(request).await {
                        Ok(Response::Ok) => {}
                        Ok(response) => {
                            if incoming_tx.send(Incoming::Response(response)).is_err() {
                                break;
                            }
                        }
                        Err(e) => {
                            let message = format!("{e:#}");
                            let closed = message.contains("closed the connection");
                            let _ = incoming_tx.send(Incoming::Failed(message));
                            if closed {
                                let _ = incoming_tx.send(Incoming::Closed);
                                break;
                            }
                        }
                    }
                }
                event = client.next_event() => match event {
                    Some(message) => {
                        if incoming_tx.send(Incoming::Server(message)).is_err() {
                            break;
                        }
                    }
                    None => {
                        let _ = incoming_tx.send(Incoming::Closed);
                        break;
                    }
                },
            }
        }
    });
    (requests_tx, incoming)
}

        let size = guard.terminal.size()?;
        layout = ui::areas(Rect::new(0, 0, size.width, size.height), app.projects.len());
        send_all(&requests, app.set_pane_size(layout.pane_inner.width, layout.pane_inner.height));
        guard.terminal.draw(|frame| ui::draw(frame, &app, &layout, Instant::now()))?;

        let effects = tokio::select! {
            event = input.recv() => match event {
                Some(Term::Key(key)) => app.on_key(key),
                Some(Term::Paste(text)) => app.on_paste(text),
                Some(Term::Wheel { up, col, row }) => wheel(&mut app, &layout, up, col, row),
                Some(Term::Resize) => Vec::new(),
                Some(Term::Gone) | None => return Ok(()),
            },
            message = incoming.recv() => match message {
                Some(Incoming::Server(message)) => app.apply_server(message),
                Some(Incoming::Response(response)) => app.apply_response(response),
                Some(Incoming::Failed(error)) => { app.fail(error); Vec::new() }
                Some(Incoming::Closed) | None => {
                    drop(guard);
                    anyhow::bail!("the daemon stopped");
                }
            },
            _ = hangup.recv() => return Ok(()),
            _ = terminate.recv() => return Ok(()),
            _ = interrupt.recv() => return Ok(()),
            _ = tick.tick() => Vec::new(),
        };
        for effect in effects {
            match effect {
                Effect::Send(request) => { let _ = requests.send(request); }
                Effect::Quit => return Ok(()),
                Effect::StopDaemonAndQuit => {
                    let _ = requests.send(Request::Shutdown);
                    let _ = tokio::time::timeout(Duration::from_secs(3), async {
                        while let Some(message) = incoming.recv().await {
                            if matches!(message, Incoming::Closed) { break; }
                        }
                    }).await;
                    return Ok(());
                }
            }
        }
    }
}
```

`TerminalGuard` owns `terminal: ratatui::DefaultTerminal` and `enhanced: bool`. Keep the guard alive for the whole loop, and drop it (restoring the terminal) before returning any error to `main`. An early `return Ok(())` drops it naturally.
